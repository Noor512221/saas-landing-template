# 🚀 Modern SaaS Landing Page Template

A clean, responsive, and high-converting SaaS landing page starter kit built with **Next.js 15 (App Router)**, **Tailwind CSS**, and **Lucide Icons**. Designed for indie hackers, developers, and startups looking to launch products fast.

---

## 🌐 Live Demo

👉 **[View Live Demo](https://saas-landing-template.vercel.app)** *(Replace with your Vercel URL)*

---

## ✨ Features

- ⚡ **Next.js 15 App Router** – Modern, performant, and SEO-friendly.
- 🎨 **Tailwind CSS Styling** – Sleek dark-mode aesthetic with custom component styling.
- 📱 **Fully Responsive** – Optimized for mobile, tablet, and desktop screens.
- 📂 **Centralized Data File** – All content configured from `src/data/content.ts`.
- 🧩 **Modular Components** – Cleanly separated, reusable UI components.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Language:** TypeScript
- **Deployment:** Vercel
